
# Vite React Project

This repository is a Vite + React starter project.

What I set up:
- Vite project scaffold and config
- React entry in `src/main.jsx` with `App.jsx`
- A `Home` component at `src/component/Home.jsx`
- Basic styles in `src/index.css` and `src/App.css`

Getting started

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview the production build:

```bash
npm run preview
```

Project structure (important files)

- `src/main.jsx` — app entry
- `src/App.jsx` — root component
- `src/component/Home.jsx` — example page/component
- `src/index.css`, `src/App.css` — styles
